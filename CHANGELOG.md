# Resale Workbench changes

## 0.1.0 - 2026-09-13

First public release under the MIT license.

- Installable `resale-workbench` package with the `resale` command and an offline synthetic demo.
- Local configuration for research scope, Germany/EUR economic policy and manually coordinated roles.
- Evidence-bound review, explicit supported/unsupported/unresolved outcomes and human purchase decisions.
- Privacy-review workspaces, immutable original captures and hash-linked derived evidence.
- Optional Kleinanzeigen collection, requiring appropriate source permission.
- Allowlisted source packaging, archive checks and synthetic tests.

This release uses the Resale Workbench name. Existing Python module names, the `resale` command and stored evidence formats remain compatible. Live-source reliability, model availability and valuation accuracy are separate from software verification.
