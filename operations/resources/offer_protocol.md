# Truthful documentation experiment

This offline experiment prepares private Markdown drafts and records assignments.
It never publishes offers, creates marketplace duplicates, contacts buyers or
executes services. Real use requires actual ownership and reviewed deliverability.

Review each physical item's ownership, exact inspection, substantive service,
price and full mandatory disclosures. Both formatting arms render the same rows.
Every reported inspection failure remains visible, including extra protocol faults
and unverified reports. Unverified checks cannot be advertised as passed; missing
inspection or ownership review blocks a factual draft. Raw text is Markdown/HTML
escaped. A draft is not a publication approval.

Freeze the buyer-segment hypothesis, channel, seed, matched blocks and exact item
digests before assignment. Deterministic seeded permutation balances documentation
arms within each block; price, testing scope and service remain constant. One
physical item and outcome case can receive one assignment. All assigned items
must already belong to the follow-up cohort; assignment never creates a sale.

Report every assignment, including missing observations and open inventory.
Track actual inquiries, handling, support and views with unique observation IDs
and current bound review. Conversion, returns and cash follow the case ledger;
views are not the primary business endpoint. Full reconciled contribution uses
qualified actual-cost cohort reviews and remains null for unfinished cases.

Later price, service, inspection or disclosure changes invalidate the original
documentation-only contrast. Preserve declared deviations and assignments instead
of dropping difficult cases. Later service experiments need a new protocol with
incremental labor and aftercare. Neither counts nor drafts prove causal advantage.
