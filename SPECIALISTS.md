# Optional specialist workers

The default workflow has an evidence preparer followed by a valuator and human review. A specialist split is an optional experiment, not a required installation component.

Use narrowly assigned identification, source research or original-source inspection roles only when they resolve a concrete independent uncertainty. Give each worker a minimal private packet, its actual resource allowance and an output folder. Reconcile workers before retrying or starting dependent valuation. Source records must retain their kind, original evidence, locators, time and limitations. Merging workers' opinions does not create independent transaction evidence.

Measure overhead as well as task output. More workers have not been established to improve this tool's accuracy or efficiency. Keep account-specific task IDs, rollouts and research artifacts in private storage; exported support summaries must not include them. No specialist should contact sellers, purchase, change accounts or spawn more workers unless the operator explicitly authorized that work.
