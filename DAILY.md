# Repeated supervised use

Scheduling is disabled by default. This document does not create or resume a schedule. Reconcile unfinished work before starting a user-authorized run; never duplicate dispatches or replay missed days automatically.

1. Choose a local configuration and finite preparation budget. Initialize a new run with `resale run init RUN --config CONFIG`. Keep time and resource capacity for valuation and closeout. Optional case/job caps apply only if configured; there is no mandatory listing count quota.
2. Collect or import only through an authorized source path. Prepare the run's bound search URL using `resale search prepare RUN --url ...` as documented in RUNNER.md. Inspect native location/radius/category/order controls and describe category mapping. Retain posting-time uncertainty and incomplete coverage. Individual listing scope still requires inspection; time eligibility is not geographic certification.
3. Triage complete listings, retaining selected, deferred, rejected and unreviewed distinctions. Use backlog/carryover explicitly; do not relabel old observations as fresh discoveries.
4. Inspect and prepare private target inputs under RUNNER.md. Worker's capabilities are explicitly supplied local context; absent skills, tools and assistance remain unknown.
5. Prepare and dispatch evidence jobs within the budget. Keep all target/source privacy and price checks separate. Complete or reconcile all preparation jobs before valuation starts. Preserve first attempts and record corrections without rewriting original evidence.
6. Inspect valuation results substantively as well as mechanically. Apply actual cost and transaction gates separately. Retain unknowns and abstentions. Close out with evidence, coverage, outcomes and the next useful human question.

A coordinator/external executor is responsible for actual research time, token/cash limits and user notifications. The queue limits new preparation and optional counts; it cannot stop an external agent or verify source facts. See RUNNER.md for commands. No seller messaging or purchase is performed.
