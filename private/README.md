# Published research context

**This folder is public. Its name does not provide access control.** The owner explicitly requested publication of selected research results under `private/` on 14 September 2026.

Start with [RESEARCHER-START.md](RESEARCHER-START.md) for project orientation and a copyable assignment for an isolated researcher. The [14 September package](research/2026-09-14/README.md) contains the results, critical retrospective, implementation/acceptance summary and open research questions.

These are reviewed report derivatives, not an upload of the local private workspace. Original marketplace photos, raw browser/account captures, credentials, personal operator context, databases, configuration, conversations and unchecked logs are not published. Original evidence remains local; public summaries cannot independently prove its full contents or reproduce the local runs. Original and derived report hashes are recorded in the package provenance file.

This tree is repository-only context and is excluded from the software release allowlist, wheel, sdist and checked source ZIP. `.gitignore` continues to ignore private operating files by default. Only explicitly reviewed paths are tracked; do not force-add an entire private directory. Publication of these reports does not authorize future publication of operating data.
